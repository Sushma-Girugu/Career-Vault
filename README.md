# CareerVault

CareerVault is a personal career management platform that helps students manage and showcase their academic and professional journey in one place.

## ✨ Features

- 👤 User Authentication
- 📊 Career Dashboard
- 📝 Profile Management
- 🛠️ Skills Management
- 💻 Project Management
- 📄 Resume Builder
- 💼 Job Application Tracking
- 🏆 Achievements Management
- 🌐 Personal Portfolio
- 🔗 Social Profile Management

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT

### Tools
- Git
- GitHub
- Visual Studio Code
